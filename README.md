# romm-decky

A [Decky Loader](https://decky.xyz) plugin that browses a self-hosted [RomM](https://romm.app) server from Steam Gaming Mode and installs ROMs, one at a time, as Steam shortcuts that launch the right emulator.

**Status:** early development, not usable yet.

- It pairs with RomM through RomM's own device approval, so no password is typed or stored on the Deck.
- Games are installed on demand. Nothing is added to Steam until you install it.
- It uses RetroArch (Flatpak) by default, plus any standalone emulators it detects. It doesn't need RetroDECK.

## Install
Download the zip from the latest GitHub release. In Decky's developer settings, choose "Install plugin from URL" or "from ZIP".
